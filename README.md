# HerdLink

Мал аж ахуйн бүртгэл, хяналтын систем (прототип / демо).

## Файлууд

| Файл | Үүрэг |
| --- | --- |
| `index.html` | Үндсэн dashboard |
| `modules.js` | Module-уудын дэлгэрэнгүй хуудас (`MODHTML`) |
| `module-adapters.js` | Module хуудас бүрийн adapter (`MODADAPT`) |
| `SYSTEM.md` | Системийн тодорхойлолт |
| `DESIGN.md` | Дизайны шаардлага |
| `deploy.sh` | Cloudflare Pages руу байршуулах скрипт |

## Ажиллуулах

VS Code дээр `index.html` → баруун товч → **Open with Live Server**.
Фонт болон three.js CDN-ээс ачаалагддаг тул интернет хэрэгтэй.
